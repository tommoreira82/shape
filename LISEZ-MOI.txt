SHAPE - VERSION CORRIGÉE

CORRECTION IMPORTANTE : la fonction « top » empêchait le chargement dans le navigateur. Elle est renommée « shapeHeader ».

POUR TESTER SUR PC :
1. Extraire tous les fichiers du ZIP dans un dossier Shape.
2. Ouvrir le fichier index.html dans Chrome ou Edge.
3. Pour tester l'installation PWA ou le fonctionnement hors ligne, ouvrir un terminal dans le dossier et exécuter : python -m http.server 8000
4. Ouvrir http://localhost:8000

POUR IPHONE : publier l'ensemble des fichiers sur un site HTTPS puis ouvrir dans Safari > Partager > Sur l'écran d'accueil.

Les données de l'application sont locales. Exporter régulièrement les sauvegardes JSON.
